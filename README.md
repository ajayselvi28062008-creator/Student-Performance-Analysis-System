# Student Performance Analysis System

## Introduction

The Student Performance Analysis System is a data analytics project that analyzes student academic performance and identifies factors affecting student outcomes.
Using Python-based data analysis techniques, the system provides meaningful insights through interactive visualizations and statistical analysis,helping educators and institutions understand student performance trends.

## Objectives

* Analyze student academic performance data.
* Identify factors influencing student scores.
* Discover performance trends and patterns.
* Generate meaningful visual insights.
* Support data-driven educational decisions.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Dataset Features

The dataset contains information related to student performance, such as:

* Gender
* Study Hours
* Attendance
* Previous Scores
* Parental Education
* Exam Scores
* Final Grade/Result

## Exploratory Data Analysis (EDA)

**Data Cleaning**

* Missing value handling
* Duplicate removal
* Data type correction

**Statistical Analysis**

* Summary statistics
* Correlation analysis
* Distribution analysis
